# ドキュメント（GitHub Pages）

このフォルダの HTML は **GitHub Pages** で公開すると、App Store のサポート URL やアプリ内リンクの先として使えます。

## 公開手順（リポジトリ管理者向け）

1. GitHub の [ConvenienceDachi](https://github.com/shunsukesaito00/ConvenienceDachi) を開く  
2. **Settings** → **Pages**  
3. **Build and deployment**: Source を **Deploy from a branch** にする  
4. Branch: **main**（または既定ブランチ）、Folder: **/docs** を選択して Save  

公開後の URL の例（ユーザー名・リポジトリ名が一致する場合）:

| 用途 | URL |
|------|-----|
| サポート | `https://shunsukesaito00.github.io/ConvenienceDachi/support.html` |
| プライバシーポリシー | `https://shunsukesaito00.github.io/ConvenienceDachi/privacy.html` |
| 利用規約 | `https://shunsukesaito00.github.io/ConvenienceDachi/terms.html` |

※ 初回反映まで数分かかることがあります。
